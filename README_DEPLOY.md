# Deploy checklist (Supabase + Netlify)

Use this when admin uploads fail (Home Bound band members) or public data doesn't load.

## 1) Environment variables
Set these in both places:
- Local: create `.env.local` (copy from `.env.local.example`)
- Netlify: Site settings > Build & deploy > Environment > Environment variables

Required:
- VITE_SUPABASE_URL = https://isfqhascrdzaoebhuohs.supabase.co
- VITE_SUPABASE_ANON_KEY = <your anon key>

After changing Netlify envs, trigger a redeploy.

## 2) Band members table + RLS
Run this in Supabase SQL editor (on the same project as above):

```sql
-- Ensure table exists and policies allow admin actions
CREATE TABLE IF NOT EXISTS band_members (
  id bigint PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  name text NOT NULL,
  role text NOT NULL,
  image text NOT NULL,
  description text NOT NULL,
  specialty text NOT NULL,
  category text DEFAULT 'Vocals' NOT NULL,
  achievements text[] DEFAULT '{}',
  order_position integer DEFAULT 1,
  enabled boolean DEFAULT true,
  is_featured boolean DEFAULT false,
  social_links jsonb DEFAULT '{}',
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);

ALTER TABLE band_members ENABLE ROW LEVEL SECURITY;

DO $$ BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM pg_policies WHERE polname = 'Enable read access for all users' AND tablename='band_members') THEN
    CREATE POLICY "Enable read access for all users" ON band_members FOR SELECT TO public USING (true);
  END IF;
END $$;

DO $$ BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM pg_policies WHERE polname = 'Enable insert for authenticated users' AND tablename='band_members') THEN
    CREATE POLICY "Enable insert for authenticated users" ON band_members FOR INSERT TO authenticated WITH CHECK (true);
  END IF;
END $$;

DO $$ BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM pg_policies WHERE polname = 'Enable update for authenticated users' AND tablename='band_members') THEN
    CREATE POLICY "Enable update for authenticated users" ON band_members FOR UPDATE TO authenticated USING (true) WITH CHECK (true);
  END IF;
END $$;

DO $$ BEGIN
  IF NOT EXISTS (
    SELECT 1 FROM pg_policies WHERE polname = 'Enable delete for authenticated users' AND tablename='band_members') THEN
    CREATE POLICY "Enable delete for authenticated users" ON band_members FOR DELETE TO authenticated USING (true);
  END IF;
END $$;
```

## 3) Storage bucket for images
Uploads use the `band-images` bucket. Run this if it's missing or uploads say bucket not found:

```sql
INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
VALUES (
  'band-images','band-images', true, 83886080,
  ARRAY['image/png','image/jpeg','image/jpg','image/webp','image/gif']
)
ON CONFLICT (id) DO UPDATE
SET file_size_limit = EXCLUDED.file_size_limit,
    allowed_mime_types = EXCLUDED.allowed_mime_types,
    public = EXCLUDED.public;

-- RLS for the bucket
DROP POLICY IF EXISTS "Public read band-images" ON storage.objects;
DROP POLICY IF EXISTS "Auth insert band-images" ON storage.objects;
DROP POLICY IF EXISTS "Auth update band-images" ON storage.objects;
DROP POLICY IF EXISTS "Auth delete band-images" ON storage.objects;

CREATE POLICY "Public read band-images" ON storage.objects FOR SELECT TO public USING (bucket_id = 'band-images');
CREATE POLICY "Auth insert band-images" ON storage.objects FOR INSERT TO authenticated WITH CHECK (bucket_id = 'band-images');
CREATE POLICY "Auth update band-images" ON storage.objects FOR UPDATE TO authenticated USING (bucket_id = 'band-images') WITH CHECK (bucket_id = 'band-images');
CREATE POLICY "Auth delete band-images" ON storage.objects FOR DELETE TO authenticated USING (bucket_id = 'band-images');
```

## 4) Login requirement
Admin must be logged in to add band members, due to RLS. If you see "You must be logged in", login via Admin > Login.

## 5) Verify
- Go to Admin > Home Bound Band
- Add a member (upload image should auto-save)
- Save

If fail persists in production, re-check Netlify envs match the Supabase project used above and redeploy.
